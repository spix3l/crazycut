Native engine architecture

CrazyCut combines a high-performance native C++17 core engine with a responsive Flutter desktop UI. Learn how multi-threaded frame caching, FFI communication, and the background render queue operate.

1. Multi-layer architecture

The system is cleanly decoupled into two distinct runtime layers:

  • UI Layer (Flutter Desktop): Handles timeline interaction, inspectors, dialogs, and platform menus with sub-16ms render frames.
  • Core Engine (C++17): Handles video demuxing, hardware decoding (VideoToolbox / VAAPI), frame caching, compositing, and audio mixing.
  • Dart FFI Bridge: Zero-copy memory buffer sharing between native decode buffers and UI textures.

2. Audio mastering and LUFS normalization

CrazyCut features an integrated audio graph with real-time waveform generation, 3-band parametric EQ, compressor/limiter, and automatic -14 LUFS integrated loudness normalization adhering to YouTube and Spotify broadcast standards.

3. Background render queue

Exports run as independent background worker jobs. You can queue multiple export presets (4K ProRes master, H.264 Web, and 9:16 Shorts) while continuing to edit new sequences without interface lockup.
