Keyboard shortcuts reference

CrazyCut is built for high-speed, keyboard-first editing. Master standard JKL transport, ripple cuts, and keyframe navigation to cut hours off your editing time.

1. Transport and playhead

Shortcut Action Description
Space Play / Pause Toggle playback at 1x speed
J Shuttle Reverse Rewind playback at 1x, 2x, 4x, 8x acceleration
K Pause Shuttle Instantly halt shuttle playback
L Shuttle Forward Fast-forward playback at 1x, 2x, 4x, 8x acceleration
← / → Step Frame Step backward or forward exactly 1 frame
Shift + ← / → Step 1 Second Jump backward or forward 1 full second
Home / End Timeline Bounds Jump playhead to sequence start or end

2. Editing and trimming

Shortcut Action Description
⌘B or S Split Clip Blade cut at the current playhead location
Shift + Delete Ripple Delete Delete selected clip and close the timeline gap
Delete Standard Delete Delete selected clip leaving an empty gap
I Mark In Set in-point for selection or playback loop
O Mark Out Set out-point for selection or playback loop
Alt + X Clear In/Out Remove in and out boundary markers
M Add Marker Place a named timestamp marker on the timeline ruler

3. Keyframing and inspector

Shortcut Action Description
K Add Keyframe Insert keyframe on selected property (scale, pos, opacity)
[ / ] Jump Keyframe Navigate between previous and next keyframes
⌘Z Undo Revert last state modification (100% loss-free)
⌘ShiftZ Redo Re-apply undone modification
